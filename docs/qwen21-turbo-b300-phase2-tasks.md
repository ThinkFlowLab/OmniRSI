# Profile-derived operator and framework tasks

H8 same-shape rank0 profile, 3 requests x 2 steps: 192 block calls, 384 Q/K RMSNorm calls (32.17 ms Python inclusive), 768 symmetric-memory exchanges (151.81 ms kernel aggregate including waits), 10,581 CUDA kernel launches. Main production shapes are local decode `[1,880,4096]`, prefill `[1,911/913/914,4096]`, Q/K `[1,S,32,128]`, FFN `[1,S,12288]`. Aggregates overlap and include profiler overhead; none is an E2E estimate.

| Task | Evidence / isolated variable | Contract and acceptance |
| --- | --- | --- |
| H9 pointwise fusion | Repeated gate multiply + residual add, and SiLU + FFN multiply. Fuse only elementwise chains first. | Preserve intermediate BF16 rounding and disable reassociation/FMA; compare random/extreme/production shapes then full native-eight-step RGB/alpha gate. |
| H10 RoPE-only fusion | Repeated BF16->FP32, complex multiply and FP32->BF16. Leave RMS reduction untouched. | Match Torch complex multiply order and output shape/stride; full-image accuracy required. |
| H11 QK normalization components | 384 RMSNorm calls and repeated casts/scaling. Separate reference reduction from pointwise suffix to avoid H3's changed reduction. | Original mean/pow and two BF16 rounding boundaries; numeric checks and complete E2E. |
| H12 VAE normalization epilogue | `_decode_latents` 193.39 ms inclusive/3 requests; large FP32 normalize/divide/cast/scale/gamma/bias chains. | H13 exact QK reduction fusion | The installed ATen Reduce.cuh uses four adjacent values per lane, sequential combination and descending warp offsets. Require an explicit configuration choice respecting enforce-eager. |

Order follows the smallest safe feasibility probe first; promotion records will include rejected attempts. Full-image gate remains RGB and alpha SSIM>=0.99 and PSNR>=35 dB, unchanged frozen v4 validator. None of these tasks is an accepted improvement yet.
